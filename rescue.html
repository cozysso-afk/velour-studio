🛟 VELOUR FORENSIC RESCUE

앱 엔진을 로드하지 않고, 현재 주소(origin)의 브라우저 저장소만 읽어서 사라진 스토리/초안/백업 조각을 찾는 긴급 복구 도구.
중요: 먼저 스캔만 해. 자동 저장/마이그레이션/삭제는 하지 않는다. 후보가 확인되기 전에는 VELOUR 본앱에서 새 생성·이어저장을 하지 않는 게 안전하다.
아직 스캔하지 않았어.
이 페이지는 외부 서버로 데이터를 전송하지 않는다. API 키/토큰처럼 보이는 값은 후보 백업에서 제외한다. IndexedDB 복구 버튼을 누를 때만 선택한 후보를 새 작품 ID로 추가한다.
